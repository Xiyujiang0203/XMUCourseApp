# XMU 课程表

厦门大学课程表 Android 客户端：支持厦大统一身份认证（CAS）登录，查看个人课表。

## 下载安装

请到 **[Releases](https://github.com/Xiyujiang0203/XMUCourseApp/releases/latest)** 获取最新版：

**当前版本 v1.0.2**

**[XMUCourse.Apk](https://github.com/Xiyujiang0203/XMUCourseApp/releases/latest/download/XMUCourse.Apk)**

1. 将 APK 传到 Android 手机
2. 允许「安装未知来源应用」
3. 打开安装包完成安装

## 功能简介

- 厦大 CAS 账号密码登录
- 按日 / 按周查看课程安排
- 本地保存登录状态，会话过期可自动重登
- Material Design 3 主题色调节（光谱 → 课表色）
- 意见反馈（云端同步，可查看管理回复）
- 捐赠收款码（可保存到相册 / 打开支付宝）
- 一键分享应用、QQ 交流群入口

## 系统要求

- Android 手机
- 能访问校园网或可访问厦大教务 / CAS 的网络
