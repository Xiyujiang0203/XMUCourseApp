# XMU 课程表

给厦大同学用的 Android 课表 App。用学校统一身份认证（CAS）登录后，就能看自己的课表，也能查成绩、考试、培养方案，用常用工具和校园集市。

**课表是核心，日常够用**：登录、日课表 / 周课表、切学期切周、本地缓存、断线自动重登，都可以直接拿来用。

在课表之外，也已经接上不少周边能力——教务查询（成绩 / 考试 / 培养方案 / 本研选课）、图书馆书目检索与借阅信息、校历与校区地图、常用电话，以及拼车 / 二手 / 帖子集市。你可以按需使用，不必依赖官网或一堆网页入口。

## 能做什么

**课表（主力）**

- 厦大 CAS 账号密码登录
- 按日 / 按周看课，支持切学期、切周
- 登录状态本地保存，会话过期可自动重登
- 主题色可调（浅色 / 深色光谱，课表颜色跟着变）
- 黑暗模式：可跟随系统深色模式；系统浅色时使用主题色
- 上课提醒：开启后立即推送，每日 7:00 / 23:00 定时
- 桌面小控件：今明课程，支持后台刷新、滑动查看与跳转课表
- 设置「智能一页」：周课表可压缩到一屏
- 自定义课程：可管理，并纳入日程 / 提醒 / 小控件

**教务 & 更多**

- 成绩、考试、培养方案（本研分流）
- 研究生选课（方案内 / 计划内 / 非计划 / 已选 / 已开查询，预选课表预览）
- 本科生选课（多 Tab 课程查询、已选课程、条件搜索、选课检查；选课/退课待上线）
- 常用工具：校历、虚拟/静态地图、图书馆书目检索、图书馆开放时间、图书馆座位系统管理规则、翔安班车时刻表、翔安校园公交安排、健康证提示、常用电话
- 意见反馈（新建可附最多 3 张图，能看到管理端回复）
- 检查更新、分享应用、QQ 交流群、捐赠入口
- 设置可隐藏底部「集市」入口

**集市（可选）**

- 拼车：发布 / 编辑 / 删除，招募中 / 拼成 / 超时；可按日期 / 起点 / 终点筛选
- 二手：多图发布、整帖或单图标记「已售出」
- 帖子：公开楼层回复，支持配图

## 使用前看一眼

- 需要能访问厦大教务 / CAS 的网络（校园网或可访问校内服务的环境）
- 这是**非官方**第三方小工具，仅供同学学习交流使用
- 选课结果以学校官方系统为准，请务必自行到官网核对
- 本仓库只放安装包和说明，源码不在这里公开

有问题可以加 QQ 群 **1079554686**，或在 App 里提交意见反馈。
