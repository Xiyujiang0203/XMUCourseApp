# XMU 课程表

厦门大学课程表 Android 客户端：支持厦大统一身份认证（CAS）登录，查看个人课表。

## 下载安装

请到 **[Releases](https://github.com/Xiyujiang0203/XMUCourseApp/releases/latest)** 下载最新版：

**当前版本 v1.0.1**

**[XMUCourse.Apk](https://github.com/Xiyujiang0203/XMUCourseApp/releases/latest/download/XMUCourse.Apk)**

1. 将 APK 传到 Android 手机
2. 允许「安装未知来源应用」
3. 打开安装包完成安装

## 功能简介

- 厦大 CAS 账号密码登录
- 按日 / 按周查看课程安排
- 本地保存登录会话，减少重复登录
- Material Design 3 主题色调节（更多 → 设置）
- 一键分享应用与 QQ 交流群入口

## 系统要求

- Android 手机
- 需要校园网或可访问厦大教务 / CAS 的网络环境
