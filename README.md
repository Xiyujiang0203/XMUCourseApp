# XMU 课程表

厦门大学课程表 Android 客户端：支持厦大统一身份认证（CAS）登录，查看个人课表。

## 下载安装

直接下载本仓库中的安装包：

**[XMU课程表.Apk](./XMU课程表.Apk)**

1. 将 APK 传到 Android 手机
2. 允许「安装未知来源应用」（或仅允许该文件管理器安装）
3. 打开 `XMU课程表.Apk` 完成安装

## 功能简介

- 厦大 CAS 账号密码登录
- 按日查看课程安排
- 本地保存登录会话，减少重复登录

## 系统要求

- Android 手机
- 需要校园网或可访问厦大教务 / CAS 的网络环境
