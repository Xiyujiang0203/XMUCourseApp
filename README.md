# XMU 课程表

给厦大同学用的 Android 课表 App。用学校统一身份认证（CAS）登录后，就能看自己的课表。

**课表相关的基础功能已经基本做完了**——登录、日课表 / 周课表、切学期切周、本地缓存、断线重登这些日常会用到的，都可以正常用。如果你只是想找个顺手的课表，**可以放心下载安装，直接投入使用**。

后面还会继续加一些「周边」能力（教务查询、拼车二手等），不影响你把课表当主力工具来用。

## 能做什么

**课表（主力）**

- 厦大 CAS 账号密码登录  
- 按日 / 按周看课，支持切学期、切周  
- 登录状态本地保存，会话过期可自动重登  
- 主题色可调（浅色 / 深色光谱，课表颜色跟着变）

**教务 & 更多**

- 成绩、考试、培养方案（本研分流）  
- 意见反馈（能看到管理端回复）  
- 检查更新、分享应用、QQ 交流群、捐赠入口  

**集市（可选）**

- 拼车：发布 / 编辑 / 删除，招募中 / 拼成 / 超时  
- 二手：多图发布、整帖或单图标记「已售出」  

## 使用前看一眼

- 需要能访问厦大教务 / CAS 的网络（校园网或可访问校内服务的环境）  
- 这是**非官方**第三方小工具，仅供同学学习交流使用  
- 本仓库只放安装包和说明，源码不在这里公开
